Two.js (jonobr1/two.js, MIT, ~8.7k stars) — renderer-agnostic two-dimensional drawing API for the web. Draw shapes, curves, and text once and render to SVG, Canvas, or WebGL; animate them frame by frame. Docs: https://two.js.org — repo: https://github.com/jonobr1/two.js

Install:
```
npm install two.js
```
Verified package `two.js` 0.8.24, MIT. No account or GPU needed.
When to use vs alternatives: pick Two.js for flat 2D vector scenes and shape animation on the web. For interactive canvas apps with events/layers use Konva; for full programmatic video use Motion Canvas or Remotion; for timeline/easing on DOM use Anime.js.
