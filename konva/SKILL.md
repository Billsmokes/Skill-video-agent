Konva (konvajs/konva, MIT, ~15.0k stars) — HTML5 Canvas JavaScript framework for desktop and mobile. Layers, shapes, events, drag-and-drop, filters, and animation on canvas — the modern successor to KineticJS. Docs: https://konvajs.org — repo: https://github.com/konvajs/konva

Install:
```
npm install konva
```
Verified package `konva` 10.9.1, MIT (LICENSE file in repo confirmed MIT; GitHub's license detector reports NOASSERTION, ignore that). No account or GPU needed.
When to use vs alternatives: pick Konva for INTERACTIVE canvas apps (drawing tools, editors, drag-and-drop). For flat non-interactive 2D drawing use Two.js; for timeline/easing animation use Anime.js; for programmatic video use Motion Canvas or Remotion.
