Babylon.js (BabylonJS/Babylon.js, Apache-2.0, ~26.4k stars) — powerful, open 3D engine for the web. Scenes, PBR materials, physics, XR, GUI, animation tools; a full game-engine-style API in the browser. Docs: https://doc.babylonjs.com — site: https://www.babylonjs.com — repo: https://github.com/BabylonJS/Babylon.js

Install:
```
npm install @babylonjs/core
```
Verified package `@babylonjs/core` 9.36.0, Apache-2.0. No account needed. A GPU helps (WebGL); runs on CPU fallback.
When to use vs alternatives: pick Babylon.js for full-featured 3D web apps/games with a batteries-included engine. For a lighter, lower-level 3D library use Three.js; for agent-driven 3D scenes use the 67.js engine already installed here (`build-67js-scene` skill); for offline film-quality 3D use Blender; for a standalone game engine use Godot.
