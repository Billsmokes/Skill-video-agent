Shifty (jeremyckahn/shifty, MIT, ~1.6k stars) — small, fast TypeScript animation (tweening) engine. Tweens any numeric values with easing, promises, and a tiny API; no DOM dependency. Repo: https://github.com/jeremyckahn/shifty

Install:
```
npm install shifty
```
Verified package `shifty` 3.0.9, MIT. No account or GPU needed.
When to use vs alternatives: pick Shifty for lightweight programmatic tweening in JS/TS. For DOM/SVG timeline animation use Anime.js; for React UI animation use Motion; for CreateJS-ecosystem tweening use TweenJS; for number interpolation only use Ola.
