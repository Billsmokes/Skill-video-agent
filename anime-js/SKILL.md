Anime.js (juliangarnier/anime, MIT, ~74.7k stars) — lightweight JavaScript animation engine. Timelines, staggering, easing, morphing; works on DOM, SVG, CSS properties, and plain JS objects. Docs: https://animejs.com — repo: https://github.com/juliangarnier/anime

Install:
```
npm install animejs
```
Verified package `animejs` 4.5.0, MIT. No account or GPU needed. v4 is the current major version; v3 docs/examples differ, so check the version in the project first.
When to use vs alternatives: pick Anime.js for general-purpose web animation with timelines and staggering. For React UI animation use Motion; for pure tweening with the smallest API use Shifty or TweenJS; for number interpolation only use Ola; for video rendering use Remotion.
