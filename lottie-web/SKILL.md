Lottie Web (airbnb/lottie-web, MIT, ~32.5k stars) — renders After Effects animations exported as JSON (Bodymovin) natively on web. Small, vector-based animations: icons, loaders, illustrations that move. Repo: https://github.com/airbnb/lottie-web

Install:
```
npm install lottie-web
```
Verified package `lottie-web` 5.13.0, MIT. No account or GPU needed. Needs a `.json` animation file (exported from After Effects with Bodymovin, or downloaded from LottieFiles).
When to use vs alternatives: pick Lottie Web only to PLAY existing After Effects JSON animations. To CREATE animation from code use Motion Canvas, Remotion, or Anime.js; to export your own animation as Lottie JSON, build it in After Effects (or with the Lottie creator tools), not with this package.
