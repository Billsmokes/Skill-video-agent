Godot Engine (godotengine/godot, MIT, ~120.2k stars) — free, open-source, multi-platform 2D and 3D game engine. Scene tree, GDScript/C#, animation tools, physics, export to desktop/mobile/web. Docs: https://docs.godotengine.org — site: https://godotengine.org — repo: https://github.com/godotengine/godot

Install: download the editor from https://godotengine.org/download — there is NO npm/pip package. The editor is a single large binary (hundreds of MB); do NOT clone the repo (huge). No account needed. A GPU helps for 3D; 2D work runs fine on CPU.
When to use vs alternatives: pick Godot for GAMES or real-time interactive animation. For video/animation rendering use Remotion, Motion Canvas, or Blender instead — Godot is a game engine, not a video renderer. For web 3D without a game engine use Three.js or Babylon.js.
