Proton (drawcall/Proton, MIT, ~2.5k stars) — JavaScript particle animation library. Emitters, behaviours (gravity, wind, turbulence), and renderers for canvas/DOM/WebGL; good for fire, smoke, sparks, confetti, and trails. Repo: https://github.com/drawcall/Proton

Install:
```
npm install proton-js
```
Verified package `proton-js` 3.1.2, MIT. No account or GPU needed.
When to use vs alternatives: pick Proton only for PARTICLE effects on the web. For general animation use Anime.js, Motion, or Shifty; for 3D scenes use Three.js or Babylon.js (both have their own particle systems for 3D); for video rendering use Remotion or Motion Canvas.
