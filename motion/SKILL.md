Motion (motiondivision/motion, MIT, ~35.2k stars) — modern animation library for JavaScript and React (successor to Framer Motion's engine, aka Motion One). Springs, timelines, gestures, layout animation, WAAPI-based. Docs: https://motion.dev — repo: https://github.com/motiondivision/motion

Install:
```
npm install motion
```
Verified package `motion` 14.14.0, MIT. No account or GPU needed.
When to use vs alternatives: pick Motion for UI/page animation in React/JS apps. For video rendering use Remotion; for raw timeline/easing use Anime.js or Shifty; for number interpolation only use Ola; for canvas 2D drawing use Two.js or Konva.
