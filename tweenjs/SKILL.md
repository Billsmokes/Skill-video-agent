TweenJS (CreateJS/TweenJS, MIT, ~3.6k stars) — simple but powerful tweening/animation library for JavaScript, part of the CreateJS suite (EaselJS, SoundJS, PreloadJS). Chain tweens, easing, delays, and callbacks. Repo: https://github.com/CreateJS/TweenJS — docs: https://createjs.com

Install:
```
npm install @createjs/tweenjs
```
Verified package `@createjs/tweenjs` 2.0.0-beta.4, MIT. Note: the current npm release is a beta; the stable 1.x line is older. Last repo push 2023-12-18 — mature/stable, not actively developed. No account or GPU needed.
When to use vs alternatives: pick TweenJS mainly inside CreateJS projects. For new general-purpose tweening prefer Anime.js or Shifty (actively maintained); for React UI animation use Motion.
